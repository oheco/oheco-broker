# oheco-broker v0.1.0

首个正式版本，目标平台：HarmonyOS/OpenHarmony `ohos-arm64`。原生构建工具链为 Go `1.27.1-ohos.1`；C/.NET SDK 同版本以源码形式随包提供。

## 安装与使用

```sh
oo update
oo install oheco-broker
oheco-broker --version
oheco-broker
```

服务前台运行，监听系统分配的 `127.0.0.1` 端口，将一行 `127.0.0.1:端口` 原子写入 `~/.oheco/broker/endpoint`。Ctrl+C 或 SIGTERM 正常停止；不自动启动，不创建系统服务，不需要配置文件。

运行服务只需要系统 `libc.so`，不依赖 Go/.NET/clang。要执行的 dotnet、git 等工具需要自行安装并由终端环境提供。

## SDK 与协议

- C：`sdk/c/oheco_broker.{h,c}`，直接编译进宿主；可用 CMake OBJECT target，不要求独立 `.a`/`.so`。
- .NET：`sdk/dotnet/Oheco.Broker.csproj`，纯 .NET 10；支持 ProjectReference 或直接包含 `BrokerProcess.cs`，无 P/Invoke 或外部 NuGet 依赖。
- 简单二进制协议，一条连接执行一个命令；不使用 JSON。
- 支持参数数组、工作目录、环境变量覆盖、stdin/stdout/stderr、退出结果、等待与取消。
- 发现文件读取/格式错误及连接失败统一为 `OHECO_BROKER_ERR_UNAVAILABLE` / `BrokerErrorCode.Unavailable`。

默认安装的 SDK 路径为 `~/.oheco/packages/oheco-broker/0.1.0/sdk/`。完整服务源码、许可证、测试及协议说明也在发行包内。

## 重要限制

**没有鉴权或加密。任何能连接端口的本机应用均可请求以终端身份执行命令；共享发现文件也不能认证服务身份。仅供可信本机开发使用，不应以 root 运行或无人值守，使用完关闭。随机端口不是安全措施。**

不包含 PTY、文件同步、自动路径映射、断线恢复、后台脱离任务、完整 Process 兼容性或对主动脱离进程组后代的绝对清理保证。阻塞的内核文件系统/exec 调用无法被 Go 上下文强制中断。

本版本未修改 Godot，未将正式 SDK 接入真实 Godot HAP；终端侧 SDK 验收不代表所有应用权限组合、设备或系统版本都已验证。最终游戏不应依赖本服务。
