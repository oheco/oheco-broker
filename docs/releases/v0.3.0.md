# oheco-broker v0.3.0

平台：HarmonyOS arm64。新增 Go/SQLite 管理服务、WS/WSS 持续信令、Pion STUN/TURN、双向密码认证的 C peer 与 TCP/UDP 映射；Go SDK/CLI 通过 cgo 调用同一 C 引擎。原本地命令服务改为显式 `shell serve`，无参数显示帮助。

## 安装与发行内容

```sh
oo update
oo install oheco-broker
oheco-broker --version
oheco-broker --help
oheco-broker-server --help
```

发行包包含客户端启动器、签名 CLI、随包签名 libc++ runtime、签名独立服务端，以及 **C／Go／.NET 源码 SDK**。C 的完整固定依赖、来源、许可证和离线构建资源一起提供；Go 模块锁和 vendor 支持离线消费。SDK 无预编译库，按目标平台原生构建。独立服务端不链接 C peer SDK，只依赖系统 C 运行库。

客户端启动器配置包内 C++ runtime，归档可整体迁移。安装不自动启动或部署服务。应用构建、测试与示例使用完整源码 checkout，源码 SDK 构建使用包内资源。

## 行为与限制

管理账号、审批及初次会话创建使用 REST；持续信令使用 `ob-signaling-v1` WS/WSS，断线按 consumed cursor 重连，不静默回退持续 REST 轮询。peer 密码不交给管理服务；端点通过 PAKE、证书 pin 与 TLS exporter 绑定验证对端。

映射默认监听 loopback，目标 allowlist 默认拒绝全部。租户 relay 默认禁用；FORCE 需显式授权并实际使用中继。TURN 当前 UDP/IPv4，UDP 为尽力交付；不提供 TUN、透明 TCP 续传或所有 NAT 连通率保证。

静态证书可自动热加载，换证无需服务重启且现存 WSS 连接继续；也可选择原生 ACME 自动签发／续期。原 `shell serve` 无鉴权，只适用于可信本机开发，不能暴露为远程目标。
